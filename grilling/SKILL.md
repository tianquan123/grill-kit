---
name: grilling
description: 就某个计划、决策或想法无情地拷问用户。当用户想压测自己的思路，或说出任何 "grill" 类触发词时使用。
---

无情地访谈用户，直到达成共识。把它建模成一棵**决策树**：每个决策都会分叉出挂在它下面的决策。

按**轮次**推进这棵树。**当前可问的问题**是指所有前置条件都已确定、你现在就能问而不必猜测答案的那些决策 —— 也就是此刻可以问的全部问题。一轮之内把当前可问的问题全部问完：给每道题编号，并附上你推荐的答案。然后等用户回答，再进入下一轮。

## 用什么问：默认 `ask_user_question`

**一个轮次 = 一次 `ask_user_question` 调用。**（Claude Code 里是 `AskUserQuestion`；没有等价工具时退回下面的正文格式。）

- 它是**阻塞**的：逐题调用会把一轮拆成好几轮，还会让用户在没看到 Q3 的时候就先答完 Q1。**把这一轮所有当前可问的问题放进同一个 `questions` 数组。**
- `id` 就用 `Q1`、`Q2`……与轮内编号对齐，回答回来能对上号；`header` 写短标题；`question` 写正文，可以多段（卡片按 Markdown 渲染）。
- **答案可枚举（2–5 个）才给 `options`**：推荐项放**第一个**、标签末尾加 `(推荐)`——只有第一项会被预选成草稿，用户仍然要自己提交。推荐理由写进这一项的 `description`，一句话说清代价。
- **答案是开放的**（要他讲边界、讲取舍依据、讲他那边的事实）就**不要套选项**：不给 `options`，在 `question` 里说清你想听什么，推荐答案写在回话正文里。
- 不要为了「用上工具」硬造选项：三个都不对的按钮，比一道开放题更耽误事。

提问之前，先在正文里说清这一轮为什么这么问、以及你已经查到了什么事实；题面与选项进调用，不要在两处重复贴。

## 一轮的格式（工具不可用时）

没有提问工具、或调用被拒时（**存活子代理调不了这个工具**，会以 `DELEGATED_CALLER` 拒绝），用正文问：

```
❓ **Q1** - **<问题标题>**：<问题正文，可以多段，可以包含多个选项>

➡️ <你推荐的答案>

---

❓ **Q2** - **<问题标题>**：<问题正文，可以多段，可以包含多个选项>

➡️ <你推荐的答案>
```

## 回答怎么记

- **没作答的题**（空 `selected`）不算定案：下一轮重问，或者在动手前显式列为未决。
- 用户手写的答案（`custom`）优先于任何选项标签，按它记决策，不要退回那串标签文本。
- 回答回来后，把落定的决策**一条一句话写回正文**——卡片是提问界面，不是决策记录。

用户每一轮的回答都会重塑这棵树：落定的决策会解锁下一批可问的问题。重新找出当前可问的问题，问下一轮。**如果一道题的答案依赖本轮里另一道还没定的题，它属于*后面*的轮次，不属于本轮。**

**找事实是你的活，永远不是用户的活。** 当前可问的问题需要从环境（文件系统、工具等）里取事实时，派一个子代理去找；凡是你能自己查到的，都不要问用户。不要为此阻塞：一个正在跑的探查就是一个尚未确定的前置条件，所以只有它下游的问题需要等子代理回报，其余可问的问题现在就问。**提问不能外包给子代理**——存活子代理调不了提问工具，替用户做决定的必须是你自己。**决策是用户的**：每一条都摆给他，然后等。

## 深度随档位缩放

这个技能被不同的入口以不同的深度调用（见 `use-grill`）：

- **局部档**：只问**答案会改变做法**的那几题，通常一轮就够。目标是够动手，不是把树走完。
- **架构档**：问到**没有可问的问题**才算结束——没有任何东西被默默假定。

两档共用同一条判据：**这一题我自己查得到吗？** 查得到就去查（见上），查不到、而答案又会改变做法，才值得占用用户的时间。

## Red Flags

| 念头 | 现实 |
|---|---|
| 「这道题先跳过，边做边定」 | 那是把不确定性留给了实施阶段 |
| 「我知道他会怎么选」 | 知道不是决定。摆给他 |
| 「问得差不多了，可以动手了」 | 架构档的结束条件是**没有可问的问题**，不是「感觉够了」 |
| 「这条我自己猜一个吧」 | 猜出来的是假定，不是共识 |
| 「一题一次调用，界面更清爽」 | 它是阻塞的：一轮一次调用，否则你把一轮拆成了好几轮 |
| 「这题不好给选项，硬凑三个吧」 | 凑出来的选项就是在替他削减问题。开放题就该开放问 |
| 「推荐项已经预选了，等于他同意了」 | 预选只是草稿，**提交**才算答 |
| 「他点了跳过，那就是默认同意」 | 跳过是没答，不是答了「是」 |

**架构档**下，当没有可问的问题时本次会话结束：决策树的每个分支都走过了，没有任何东西被默默假定。**局部档**下，问完会改变做法的那几题就结束，不必等到没有可问的问题。无论哪档，在你确认已达成共识之前，不要动手。
